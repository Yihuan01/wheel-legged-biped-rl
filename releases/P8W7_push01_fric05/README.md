# P8W7_push01_fric05（两轮地形线随机化交付档）

属主：[Ubuntu/zcode]｜2026-11-01 打包｜模型：`model_2800.pt`（iter 2800）

## 这是什么

P8W 两轮地形线的**随机化交付档**：训练分布含**推扰 0.1 m/s@10s（20% env）＋ 摩擦 ±5%（20% env）**，
其余 80% env 为名义（nominal_env_fraction=0.8）。地形 = 无向随机起伏（2026-10-31 真实化后的 ±2/±4/±8 cm 阶梯）。

## 训练链

W3@2200（V0.19，平地行走定版）
→ **P8W6a**（新阶梯适应 300 iter，lr 1e-4，无 DR）→ 2425
→ **P8W7c**（推扰 0.1，nominal 0.8，400 iter）→ 2750
→ **P8W7e**（+摩擦 ±5%，400 iter）→ **2800（本包）**

防崩三件套（四连败教训，W 线 2026-10-24）：强基座（W3 系）＋ nominal 混环境 0.8（推扰/摩擦/质量均有名义门）＋ 热启动 lr 3e-4→1e-4。全程零崩签（对照 W13/W13b/W14/W15 的"峰后单调衰"签名）。

## 验收（预注册五门槛：绝对存活/绝对进度/地形无害/不倒退/速度跟踪）

| 口径 | 结果 |
|---|---|
| 名义 24 格（留出图 s1，cmd 0.3） | 存活 min 30/32、进度 0.945~1.029 格、vx 0.288~0.301，**good=True** |
| 组合包络 24 格（推扰 0.1＋摩擦 ±5% 同开） | 存活 min 30/32、进度 0.943~1.039、**good=True** |
| 平地 cmd 0.6 | 32/32、vx 0.584（W3=0.568~0.574，不降反升） |
| 训练曲线 | reward 376~397 稳定、eplen 1850~1956，无崩签 |

诚实口径：小量级随机化（推扰 ≤0.1、摩擦 ±5%、传感器半档）的包络存活，2425 零训练也达标（30~32/32）——
随机化训练的实测增量 = min-alive +1~2 env；本包的价值在**训练分布本身含随机化**（sim2real 诚实性），
而非包络读数的大幅提升。传感器侧 DR（噪声/零偏/延迟/PD）按 P8W7a 判定**未纳入**（无包络增益、名义变慢）。

## 已知限制

- 断崖类（台阶 ≥0.158 m/障碍 0.17 m/跳石）不适用（无高程观测的原理边界），另立 P8W9。
- 摩擦/推扰量程如需上探（±10~20%/0.2），须重新预注册（W13b 在 ±10%@W12 上全灭过，机制三件套只验证到 ±5%/0.1）。
- com_offset 随机化键在本 Isaac 版本无效（rigid body com 写回被忽略，2026-10-31 实测）。
