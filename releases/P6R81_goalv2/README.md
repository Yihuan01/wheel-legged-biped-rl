## 在混合部署里的角色（2026-10-27 起的交付形态）

四槽之一：**两轮/跳跃槽**。四轮 F3e 行驶、P7T 传统脚本起立交两轮后由本网接管，P7L 负责趴下。

**链上实测（uni 四槽 `P7T_脚本起立R81`，2026-10-28）**：

- 三档跳 0.05/0.10/0.15 → **65.8 / 87.9 / 73.8 mm**（复测 64.8~65.8／87.5~87.9／73.8~74.2），比单机低 10~25 mm；
- 两轮稳态 z **0.265**（单机 0.281）——已知差项，未定位；
- 交接后本网需 **1~2 s** 刹住 P7T 残留的 0.4~0.6 m/s 后滚 ⇒ 切模式必须过"停稳门"（`|vx|≤0.08` 连续 3 拍），否则会翻。
