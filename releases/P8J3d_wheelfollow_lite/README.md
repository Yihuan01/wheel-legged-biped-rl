## 判定（探针 64 env，seed 0，同参数；dip_frac 越接近 1＝保速越好）

**读法**：3a/3b 的烧胎没有复现——假说「晚蹲刹轮是策略在对抗后仰甩尾」与「浅蹲把甩尾小一档后
轮转转为无害」一致；但弱梯度（~0.4 分/事件）推不动「轮子持续转」的行为量（dip 仅 +1pp）。
3d 的净效果＝保速不伤＋落地段明显改善（事件末 1.20）。

## 与 3f 的对照（同日追加轮）

P8J3f＝增益 ×2（`releases/P8J3f_boost2x/`，留档不交付）：dip 0.63/0.77（比 3d 差 6pp/2pp，
烧胎部分回潮）、事件末 0.74/1.03 变差、**站跳 0.15 档 −6.3 mm 触发回退线**。
⇒ 结论：**轻度轮转（无增益）与浅蹲兼容且落地受益；强推轮转（×2）重新压垮机体速度与站跳高档**。
轮速跟随的可用剂量就是「开而不增」。
