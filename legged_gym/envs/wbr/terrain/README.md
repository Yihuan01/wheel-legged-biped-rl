# WBR 地形元素与地形图

属主：[Ubuntu/OpenCode]｜**2026-11-02 口径统一版**（取代 10-29 的 11 元素版）

本目录的 `.npz` 全部由**纯 numpy 离线生成器**产出，训练/回放侧只读图（不需要 GPU）。

## 七个元素（作者 2026-11-02 定稿）

按**能力维度**分四类。删除了 10-29 版的 t1 左右高低不平、t3 单边横坡、t4 纵坡、bumps 减速带、
twave 错位波浪、obs 离散障碍、stones 跳石、t6 上台阶。

| 类别 | 元素 | 定义 | L1 / L2 / L3 |
|---|---|---|---|
| 基线 | `flat` | 全 0 平面 | — |
| 连续起伏 | `wave` | **3~4 个峰，峰高与波长逐峰变化**（sin² 半波，峰间自然回 0） | 3 峰 2.0 cm / 3 峰 3.0 cm / **4 峰 4.0 cm** |
| 连续起伏 | `rand` | 各向同性随机起伏（与训练分布同算法），出生端 2 m 压平 | ±2 / ±4 / ±8 cm |
| 横向差动 | `slope` | 平地→过渡→**一侧低一侧高的平面斜坡**→高侧 **30 cm 平台**→**竖直断崖**落回平地。滚落线沿机器人 **y 轴** | 12 cm/5° · 20 cm/6.5° · **28 cm/8°** |
| 横向差动 | `speedbump` | **半宽**减速带，左右**错开布置**、高度随机，一侧 3~4 个；**轴线过渡带 y 向 0.05 m** | 3 条 2.5~3.5 cm / 3 条 3.5~4.8 cm / **4 条 3.0~6.0 cm** |
| 离散断崖 | `stairs` | 斜坡驶上**平台**→1 m→竖直下**一级**→1 m→竖直下**一级**→平地 | 10/5 · 15/7.5 · **20/10 cm** |
| 离散断崖 | `gap` | 斜坡上**平台**→1 m→**断开**（真断崖，挖到 −60 cm）→1 m 平台→斜坡回平地 | 5/6 · 8/8 · **10/10 cm** |

### 四条设计铁律

1. **可通行衔接一律 ≤10°/格**（17.6 mm）。`wave`/`rand`/`slope` 的纵向包络、`stairs`/`gap` 的上台坡都按这条做。
2. **离散断崖可以是竖直面**（作者裁定）：`stairs` 的级差、`gap` 的断口、`slope` 高侧外缘的断崖，都用竖直面直接落下，不做缓坡过渡。
3. **`slope` 受 28 cm 峰高约束**：横向占宽 2/3（3 m 区域里 2.0 m 跨度）、8° ⇒ 峰高 28 cm。超出会侧翻。
4. **`speedbump` 的 0.05 m 轴线过渡带是横向的，不受铁律 1 约束**（它不是行进方向；作者 2026-11-02 确认）。实测该过渡处坡度 31~50°，PhysX 按竖面处理，机器人靠上去会被弹开——这是**设计意图**（"中心轴线附近过渡陡一些"）。

### demo 四象限布局（作者 2026-11-02 定）

```
        +y（左）
   ┌──────────┬───┬──────────┐
   │ stairs   │   │   wave   │
   │ 3.5 m    │   │   4 m    │
   ├──────────┤中 ├──────────┤   +x →
   │          │央 │  (平地)  │
   ├──────────┼───┼──────────┤
   │   gap    │走 │   rand   │
   │ 3.5 m    │廊 │   4 m    │
   ├──────────┼───┼──────────┤
   │          │   │speedbump │
   │          │1m │   4 m    │
   └──────────┴───┴──────────┘
        −y（右）
```

- **出生点在世界原点**，四向各留 **1 m 平地走廊**（中央十字，1×1 m 交点）。
- **前区（+x，9 m）**：左半 = `wave` 4 m ｜ 平地 1 m ｜ `rand` 4 m；右半 = `slope` 4 m ｜ 平地 1 m ｜ `speedbump` 4 m。
- **后区（−x，3.5 m）**：左半 = `stairs`；右半 = `gap`。**四个区域前进方向都沿 x 轴**，后区从 −x 进入，元素沿 x 镜像。
- `slope` 在右区**离中央走廊近的一侧低、外侧高**，高侧 30 cm 平台贴在 y=−3.5 边缘，再断崖落地。

## 生成与探针

```bash
python3 wbr_terrain_gen.py --level all      # 单元素图 L1/L2/L3
python3 wbr_composite_gen.py --what all     # demo + combo L1/L2/L3
python3 wbr_rand_gen.py                     # 训练分布（如需重生成）
python3 check_terrain.py                    # 统一探针（三层检查）
```

`check_terrain.py` 替代了旧的 `check_terrain_rand/elements/composite.py` 三份，做三层检查：
① 通用（尺寸、出生点全平、非设计竖向面、NaN）；② 元素级**特征存在**（峰值 ≥ 标称 60%，防"名字在几何没了"）；
③ demo 布局（四象限范围、十字走廊全平、出生点 = 0）。
