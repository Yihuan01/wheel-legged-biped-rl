使用说明

参数 · 功能 · 快捷键 · 存储路径

参数说明

起立方案P7S＝学习策略相位机（对齐/起立/交接，可调 t_align / t_rise / t_handover 与腿 P 倍率 leg_p_gains）；P7T＝传统脚本链（静稳→折蹲→伸腿→恒力矩抬升→交 W3，可调 t_trad_* / trad_torque / trad_boost / trad_hcmd）。
相位时长t_align / t_rise / t_handover / t_lower / t_tilt / t_absorb：起立与趴下各相位的持续时间（秒），写入 env.sw，重启生效。
传统起立参数静稳/折蹲/蹲稳/伸腿时长、抬升超时上限、恒定轮力矩 C、伸腿腿 P 倍率、交 W3 体高与保持时长；standup_mode=P7T 时生效。
五路指令vx 前进线速度、yaw 偏航角速度、height 躯干目标高度、roll 侧倾压弯角、jump 跳跃升高量。滑块两侧显示当前加载模型的指令量程（四轮/两轮各自量程不同）。

功能说明

启动 / 停止 / 校验「校验」做启动预检（权重存在、维度匹配、显卡、训练进程）；「启动仿真」按当前模式（双模式 / 单策略）拉起 Isaac Gym；「停止」结束仿真。
起立 / 趴下 / 复位四轮下可「起立」进两轮、两轮下可「趴下」回四轮；「复位」随时把机器人摆回四轮起点。
装填跳 / 连跳两轮可跳（双模式第③格用含跳跃的两轮模型如 R81；单策略模式下亦可用）。装填一次跳跃（触发键 H）；装填后约 arm_delay（默认 0.1s）站定即起跳（双模式回放已调快，接近单策略瞬时起跳）；「连跳」为自动循环跳跃。
场景 / 检查点库双击条目即加载：场景→套用该场景（四槽或单策略），固化存档→加载到单策略。每条最右两个图标：笔（提示「覆写到本条」）用当前右侧编辑区/单策略内容覆写该条，会弹保存窗口、命名确认后覆写；垃圾桶（提示「删除本条」）弹确认后删除。单策略区另有「固化检查点」按钮（命名后把当前 checkpoint 存入检查点库）。
数据绘图读取遥测日志画曲线（单策略 wbr_tel_* 与双模式 wbr_switch_tel_* 共用同一套五列模板）：列1 线速度/偏航/滚转/高度跟随，列2 竖直速度/跳跃/相位，列3–5 髋/膝/轮（位置+扭矩）。相位图纵轴只印数字（0–11），鼠标扫过「相位」图标题会浮出编号↔中文对照；支持时间窗、自动跟随、整页/分图导出。
原生窗口停靠仿真视口不抓流，把 Isaac Gym 原生窗口去边框置顶覆盖到视口；需在真实浏览器窗口/标签页里用。

相位编号（统一 0–11）

总览统一相位贯穿「两轮 / 跳跃 / 四轮 / 起立 / 趴下」，是 sim2sim / sim2real 共用的状态编号。数据绘图的「相位」图纵轴、仿真运行页的相位号都按此编号；相位图纵轴只印数字，鼠标扫过「相位」图标题即可浮出编号↔中文对照。
0 两轮待机 1 预蹲 2 爆发伸腿 3 腾空收膝 4 落地前伸腿 5 缓冲 6 四轮静稳 7 起立转起 8 起立交接 9 趴下降高 10 趴下探地 11 趴下吸能
跳跃 1–5仅两轮可跳时进入（1 预蹲 → 2 爆发伸腿 → 3 腾空收膝 → 4 落地前伸腿 → 5 缓冲），跳完回到 0 两轮待机。
旧模型说明控制层内部相位是「重载」的（四轮/起立/趴下＝切换机 0–6，两轮＝跳跃机 0–5），已训练网络依赖其原值。控制台在显示与绘图时把它补丁映射到 0–11；日志同时保留原始 ph 与统一 uni_ph，新模型今后原生输出 0–11。
